Satu platform untuk portfolio projek, penghantaran kerja, helpdesk, kewangan milestone, dan kapasiti pasukan — direka untuk persekitaran kerajaan / PBT.

Team briefing · 2026 1

Overview

Why this system?

  • One place for projects, tasks, issues, backlog, and billing milestones
  • Government-ready — engagement types (Contract, LO, PO), delivery scopes, phase templates
  • Traceable flow — Helpdesk → Backlog → Task → Delivery phase → Finance
  • Role-based — PMO, Finance, Admin, and team members see what they need
  • Notifications — in-app bell + email when SMTP is configured

Matlamat: kurangkan spreadsheet berasingan dan pastikan status projek sentiasa boleh diaudit.

PMO CTSB4

Command Center

Dashboard

  • Portfolio health — on track, at risk, blocked projects
  • Active projects, overdue tasks, team overload indicators
  • Helpdesk & backlog KPIs at a glance
  • Quick links into Projects and Helpdesk

Pusat kawalan untuk PMO — lihat kesihatan portfolio tanpa buka satu-satu projek.

PMO CTSB5

Projects

Project portfolio

  • Engagement type — Contract, Letter of Offer (LO), PO, MOU, Tender, etc.
  • Grid or list view with health badges, progress, overdue counts
  • Filter by status, health, engagement type; search by name/client
  • Link multiple client companies per project
  • Create project wizard — schedule, clients, engagement

Jenis kontrak (Kontrak/LO) di peringkat projek — bukan jenis kerja (dev/API).

PMO CTSB6

Projects

Work packages

  • One project can contain multiple delivery lines
  • Each package has its own delivery scope — e.g. Portal dev, API integration, Data migration
  • Own phases, tasks, backlog, and finance totals per package
  • Ideal for mixed engagements under a single contract

Contoh: Projek Portal PBT dengan 3 work package — portal, payment API, data import.

PMO CTSB7

Project workspace

Inside each project

Tabs

  • Overview — health, timeline, team snapshot
  • Work packages
  • Backlog
  • Tasks (groups & subtasks)
  • Delivery & payment phases
  • Timeline
  • People & allocation %

Deep links

Open directly to a tab, e.g.:

/projects/1?tab=tasks

Notifications link straight to the relevant tab.

PMO CTSB8

Service desk

Helpdesk

  • Log issues — priority, category, client, project, assignee
  • Statuses: Open, In progress, Waiting on client, Resolved, Closed
  • Filter all issues or My issues
  • Click issue title for detail; assign from table
  • Promote to backlog — converts issue into scoped backlog item
  • Assignee gets in-app notification (+ email if configured)
PMO CTSB9

Workflow

Helpdesk → Backlog → Task

Helpdesk issue → Backlog item → Project task → Delivery phase → Finance milestone
  • Backlog types: scope, CR, bug, enhancement, support, data, recurring
  • Tasks support groups, subtasks, assignees, progress %, dates
  • Filter tasks/backlog by work package when project is multi-scope
PMO CTSB10

Delivery

Phases & milestones

  • Phase templates by delivery scope — URS, UAT, Go-live, Maintenance, etc.
  • Per phase: status, progress %, target date, payment amount
  • Payment status: Pending → Invoiced → Paid
  • Initialize template per project or per work package
  • Finance sees completed phases ready to bill

Setiap fasa boleh ada nilai tuntutan — Finance track claim ikut milestone.

PMO CTSB11

Finance

Delivery & payment

  • Ready to bill — completed phases, pending payment
  • Invoiced — awaiting client payment; mark paid when received
  • Paid & claimed — audit trail per phase (invoice no., paid date)
  • Maintenance renewals — expired / ending-soon contracts for follow-up
  • Portfolio & work-package collection %; export CSV
PMO CTSB12

Personal

My work

  • Single queue: tasks, backlog, helpdesk assigned to you
  • KPIs: overdue, due this week, critical/high priority
  • Needs attention strip for urgent items
  • Mark task done inline; open project or issue directly
  • Schedule tab — today's calendar activities

Untuk developer/support — semua kerja assigned dalam satu skrin.
